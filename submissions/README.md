# 训练营作品提交区

请在本目录中创建一个以你的 **GitHub 用户名**命名的 Markdown 文件：

```text
submissions/<GitHub用户名>.md
```

例如：

```text
submissions/shenjackyuanjie.md
submissions/octocat.md
```

每位参与者原则上只维护自己的文件。

## 提交文件建议内容

```markdown
# GitHub 用户名

## 选择路线

路线一 / 路线二 / 路线三

## 项目简介

简单说明你做了什么。

## 项目 / PR

- 仓库：
- PR：
- Demo：

## 训练营期间的主要增量

说明训练营期间具体完成了哪些内容。

## 过程记录

可以附上：

- commit
- issue
- PR
- release
- 开发日志
- 截图
- Demo / 录屏

## 我学到了什么

简单说明实现过程中学习的新内容、遇到的问题以及解决方式。

## 其他说明

如果是多人项目、旧项目或闭源项目，请特别说明自己的实际贡献范围。
```

## 注意事项

1. 文件名必须使用自己的 GitHub 用户名。
2. 不要修改其他参与者的提交文件。
3. 一个 PR 原则上只提交自己的登记文件。
4. 请提交训练营期间产生的真实增量。
5. 不要通过 typo、README 小修改、纯格式化等方式刷 PR。
6. 使用 AI 辅助开发没有问题，但应能够理解并解释最终提交内容。
7. 项目不一定必须被上游合并，也不强制要求 CI、部署或复杂工程规范。

具体评分规则请查看仓库根目录的 [`README.md`](../README.md)。
